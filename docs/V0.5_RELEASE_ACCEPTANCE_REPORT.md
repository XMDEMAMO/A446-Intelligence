## 3 PostgreSQL 验收

`scripts/check-release.ps1` 把 PostgreSQL 设为强制门槛。未设置 `A446_TEST_DATABASE_URL` 时直接失败，不把跳过写成通过。该数据库会被测试清空，禁止指向生产库或保留数据的数据库。

集成 HEAD 必须覆盖 migration、Hub 重启、会话、Worker 凭据创建与轮换、撤销、Artifact、人工介入并发单次处理和 `executorAgentId` 恢复。A、B、C 分支合并后，如契约变化，只能调整测试夹具和断言，不能在 D 分支修改核心实现来迁就测试。

使用 [V0.5_RELEASE_EVIDENCE.example.json](V0.5_RELEASE_EVIDENCE.example.json) 复制一份仓库外的实际证据文件，逐项填写时间与证据引用。运行：

```powershell
.\scripts\check-release.ps1 -RunLiveBrowser -EvidenceFile '<absolute-path-to-release-evidence.json>'
```

验证器只接受全部九项为 `passed` 且具有时间和非空证据引用的记录。密码、Token、Cookie、数据库连接串和第三方账号资料不得写入证据文件。
