# 已知问题

## UI-001：账号与额度侧栏无法方便查看全部账号

- 状态：待修复
- 发现日期：2026-09-24
- 范围：`apps/web` 左侧“账号与额度”区域
- 现象：账号较多时，列表下方账号看不到；当前缺少明显的下拉/展开入口，用户无法方便地浏览全部账号。
- 期望：所有账号都能在侧栏中找到；可通过可滚动列表、折叠/展开详情或其他清晰控件实现。交互方案待设计，不在此记录中预先限定。
- 验收：常见窗口尺寸下可访问列表底部的每个账号；账号摘要和额度详情有明确层级；鼠标与键盘均可操作，不因折叠而丢失账号或额度信息。
- 代码定位：`apps/web/src/App.tsx` 的 `usage-section`（当前约第 1174 行起）直接渲染 `accounts` 列表。是否还存在容器滚动/布局裁切需在修复时结合实际界面确认。

## FLOW-001：人工改派后未继续独立审核和最终汇总

- 状态：待查明
- 发现日期：2026-09-24
- 范围：Hub 工作流的 replan / 分支审核 / 最终聚合
- 现象：本次三条分支在人工 replan 后均显示执行完成，但工作流快照为 `rootStatus=stalled`、`active=false`；没有为这三份新成果创建 Reviewer 任务或最终聚合任务，也没有待处理人工介入。
- 影响：分支成果不能视为通过 AI 审核，工作流无法形成可接受的最终结果。短时并发测试只能证明派发并行，不能证明完整协作闭环通过。
- 验收：人工改计划后，受影响分支按新计划执行并逐一获得独立 AI 审核；通过后自动产生最终聚合及其独立审核；无遗留分支时工作流明确进入终态，而非停在 stalled。
- 备注：记录的是本次实测状态，尚未判定根因或修复。
