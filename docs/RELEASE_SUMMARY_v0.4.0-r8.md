# A446 Intelligence v0.4.0-r8 阶段总结

发布日期：2026-09-14
阶段定位：两台个人设备、两个已登录账号的私人局域网协作原型

## 一句话说明

A446 Intelligence 让不同设备上的 AI 账号以独立 Agent 身份加入同一个任务群聊，并按照“规划 → 执行 → 审核 → 通过或返工”的流程协作；服务器只负责任务协调，不接管第三方账号登录凭据。

## 当前两设备拓扑

```text
设备 1：服务器 + GPT Plus
  ├─ Codex 规划 Agent
  └─ Codex 执行 Agent

设备 2：Gemini AI Pro
  └─ Antigravity / Gemini 审核 Agent
```

当前只有两台设备。仓库的数据结构允许以后增加设备、账号、Agent 和模型，但本版本不把尚未接入的机器写成已上线资源。

## 本阶段已经完成

- 一个根任务对应一个可观察群聊，规划、执行、审核和返工消息留在同一任务中。
- 规划 Agent 只接收任务简报、审核结论和成果引用；执行 Agent 只接收指令、必要文件与返工意见；审核 Agent 接收验收标准和完整成果。
- 执行 Agent 提交“任务简报 + 完整成果”；完整成果作为附件交给审核 Agent，不反复塞入规划上下文。
- 执行 Agent 发现上游错误时，先交审核 Agent 裁定；确认后只把纠错简报交给规划 Agent 重新安排。
- 调度时区分设备、账号、Agent 和模型，并根据角色、能力、在线状态、负载和可信额度状态选择 Agent/模型。
- Worker 支持心跳、断线重连、ACK、消息去重、串行队列、暂停、恢复、取消和本地检查点。
- Codex 和 Antigravity Adapter 支持各 Agent 独立持久会话；不同根任务不会错误共享上下文。
- 记录每次任务和累计 Token，用量可按任务、Agent 和账号汇总。
- 支持可信的机器可读额度探针；无法读取时明确显示 Unknown，不从 Token 数倒推额度百分比。
- 产物只在声明的工作区中收集，并记录大小和 SHA-256；路径穿越和符号链接逃逸会被拒绝。
- React 控制台已经按任务群聊、Agent 状态、成果附件、Token 和额度状态呈现。
- 提供两设备 Windows 启动器；固定服务器地址为 `192.168.137.1`。

## 已知问题与尚未完成

1. **精确额度尚未接通到两个真实客户端。** 当前框架已有可信额度快照接口，但 Antigravity `/usage` 与 Codex App Server 的额度读取仍需做成各自的本地 Provider 探针。因此界面可能继续显示“客户端暂无可以读取的额度快照”。
2. **模型列表尚未完全自动发现。** 调度器可以在 Worker 上报的多个模型间动态选择，但当前私人部署配置主要使用人工确认后的模型清单；后续需从本地官方客户端定期刷新。
3. **设备环境信息不完整。** 当前会上报 Node.js、平台、Adapter 和配置中指定的工具；Python、编译器、GPU、浏览器等环境尚未形成统一设备能力目录。
4. **人工介入渠道尚未完成。** 系统已有人工等待和工作流响应接口，但 QQ 机器人及其群聊身份、通知和回复映射暂未接入。
5. **权限仍是受范围约束的本地策略。** Codex 使用工作区写入、无需逐次审批；Antigravity 使用 accept-edits。尚未把“任务范围内 Full Access”和角色只读策略整理成最终产品配置。
6. **正式服务器尚未实现。** 当前 `hub.mjs` 是开发模拟 Hub，没有生产数据库、持久 Lease、跨 Worker 产物存储和生产级认证。
7. **真实两设备复杂任务仍需继续观察。** 自动测试覆盖完整角色闭环，但本版本没有再次消耗真实 Codex/Gemini 额度执行复杂压力测试。
8. **Antigravity 新会话的固定初始上下文暂不优化。** 对复杂任务应先观察并发收益、完成时间、返工率和单位有效成果的额度消耗，再决定是否重构会话策略。
9. **当前固定 IP 是过渡部署参数。** 后续改用正式服务器网络后，应替换移动热点地址，并补充自动发现或集中配置；A446 协作流量应继续绕过外网代理。

## 使用方式

1. 将发布压缩包分别解压到两台 Windows 设备。
2. 两台设备都双击 `START-A446-PRIVATE-LAN.bat`。
3. 设备 1 选择 `1`，启动服务器、网页、Codex 规划 Agent 和执行 Agent。
4. 记下设备 1 首次显示的 Private LAN token。
5. 设备 2 选择 `2`，首次输入上述 token，启动 Gemini 审核 Agent。
6. 浏览器打开 `http://192.168.137.1:5173`。

详细前置条件和故障处理见仓库根目录的 `PRIVATE-LAN-README.md` 与 `docs/USER_MANUAL.md`。
